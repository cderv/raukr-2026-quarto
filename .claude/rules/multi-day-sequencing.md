# Later sessions continue the same workshop

The same cohort attends both days. Treat later sessions as follow-ups, but add a callback only when
an earlier session established the concept. See `.claude/references/workshop-pacing.md` for the
pedagogical rationale.

## Slides

- Open a later-day deck with one short bridge from the previous session to the new scope.
- Do not introduce an established concept as new. Remind learners what they used, then add the new
  capability or scale.
- Reduce recurring structural slides to a brief recap. Do not repeat the full Day 1 explanation of
  the workshop rhythm.
- Keep deferred topics paired: if an earlier slide points forward, the later deck must pick it up.
  Update both ends when either changes.
- Verify every callback against the earlier deck. Never write `you saw X yesterday` without checking
  that X was taught.
- Put `Quick recap:` or `Callback:` guidance in presenter notes. Keep the slide body focused on the
  content.
- When a later slide feels repetitive, check whether the earlier slide claimed more than it
  demonstrated. Narrowing the earlier claim may create the cleanest setup and payoff.

After a substantial later-deck change, compare both decks and classify overlapping material:

- `REPEAT`: teaches the same concept from the beginning; rewrite or remove it.
- `PARTIAL`: adds something new but repeats an established definition; trim the repeated part.
- `CLEAN`: genuinely new or a concise reminder that widens the scope.

Run the comparison in both directions so false callbacks are caught too.

## Labs

Practice is useful when the same skill produces a new outcome or works in a new context. Remove or
reframe a step that repeats the same task for the same outcome. State the new dimension in the step
so participants understand why they are repeating the skill. When possible, ship prior-day work in
the starter so the later lab begins at the new layer.
